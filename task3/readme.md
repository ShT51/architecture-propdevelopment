## Описание интеграции с внешними партнерами и требования к внешним интеграциям

1. Взаимодействие с партнерскими API через новый сервис `API Gateway` на стороне *PropDevelopment*.  
На нем реализуем *ФЛК* + аутентификацию через *OAuth 2.0 (JWT токен)* + *RBAC* (к примеру: `жилец`, `гость`, `доставка`).
Доступ до сервисов "Умного дома" будет только у авторизированных пользователей, дополнительно можно добавить *MFA*.
2. Можно включить модуль для работы с новыми функциями в сервис `tenant-core-app`, но можно будет вынести в будущем и в отдельный сервис
3. Передача данных пользователей партнерам, только после их согласия. Если партнер, предоставляющий функционал "Умного дома",  
находится за пределами РФ, необходимо учесть факт трансграничной передачи данных для соблюдения 152-ФЗ.
Биометрию пользователей (снимок лица) не храним на стороне *PropDevelopment*, нам она не нужна, выступаем тут в качестве прокси.
4. Шифрование по *TLS 1.2+* для всех интеграция со внешними API. Можно также добавить *IP-whitelist* для API партнеров.
5. Добавляем новый сервис управления информационной безопасностью и событиями безопасности (*SIEM*).  
Его задача выявлять потенциальные угрозы целостности и оповещать администраторов системы и собственников о подозрительной активности  
(_следует добавить отдельный сервис нотификации пользователей, к примеру через телефонный звонок и пуш уведомление_)
